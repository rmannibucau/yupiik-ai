Configuration is resolved from, highest priority first:

. CLI arguments: `--yca-<key> <value>` (for example `--yca-provider-model`)
. JSON file: `~/.yupiik/coding-agent/configuration.json` (override the location
  with the `yca.configuration.json` key)
. System properties: `yca.provider.model` style keys
. Environment variables: `YCA_PROVIDER_MODEL` style keys (dots/hyphens become
  underscores, uppercased)

The main configuration groups are documented below. Command specific options
(`run.*`, `tui.*`) are documented in the
xref:cli/index.adoc[CLI reference].
