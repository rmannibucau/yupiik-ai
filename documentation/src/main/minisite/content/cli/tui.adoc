:minisite-nav-prev-link: index.html
:minisite-nav-prev-label: CLI

== Description

Interactive terminal UI session with the yca coding agent.

== Synopsis

[source,bash]
.tui-sample
----
java ... io.yupiik.fusion.framework.api.main.Launcher \
    tui \
    --permitAll ...\
    --showThinking ...\
    --theme ...\
    --vimBindings ...
----

== Parameters

--permitAll::
Bypass permission prompts and allow all tool calls (not persisted to the transcript).

--showThinking::
Show the reasoning/thinking stream by default.

--theme::
UI theme: dark or light.

--vimBindings::
Use vim style key bindings.
