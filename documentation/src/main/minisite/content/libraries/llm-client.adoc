= LLM client
:minisite-nav-prev-link: ../index.html
:minisite-nav-prev-label: Libraries
:minisite-breadcrumb: Home[index.html] > Libraries > LLM client

The LLM client (parent `io.yupiik.llm:llm-client`) is a shared, provider-agnostic
abstraction over OpenAI-compatible and Anthropic endpoints. It splits into three
artifacts: a neutral core (`-api`) and one dialect implementation per provider
(`-openai`, `-anthropic`).
