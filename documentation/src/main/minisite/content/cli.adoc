yca ships two commands plus the standard fusion helpers:

[cols="a,2a"]
|===
|Command |Description

| xref:cli/tui.adoc[tui]
| Interactive terminal interface (TamboUI): markdown transcript, token gauges,
todos, thinking stream, approval modals.

| xref:cli/run.adoc[run]
| Headless one-shot execution: `--prompt` (required) and optional `--session`,
prints deltas on stdout, exits non-zero on failure.

| xref:cli/completion-bash.adoc[completion bash]
| Generate the bash completion script.

| xref:cli/index.adoc[All commands]
| Generated CLI reference for every command and option.
|===

Example:

[source,bash]
----
export OPENAI_API_KEY=sk-...
java --enable-native-access=ALL-UNNAMED -jar tui/target/tui-1.0.0-SNAPSHOT-fatjar.jar \
  run --prompt "explain the pom.xml" --yca-provider-model gpt-5-mini
----

TIP: The structural code graph (enabled by default) uses the `javac` API and
therefore needs a JDK (not a plain JRE). No extra JVM flags are required.

TUI options (`tui.*`) and run options (`run.*`) are documented in
xref:configuration.adoc[Configuration] and on each command page.
