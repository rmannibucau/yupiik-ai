= Plan and build modes
:minisite-breadcrumb: Home[index.html] > Features > Plan and build modes

yca access modes shape how the agent works:

* `plan` (the default) is read-only: it inspects the codebase and records its
  approach as pending todos instead of making changes;
* `build` makes every tool available; entering `build` from `plan` also defaults
  the session approval mode to `auto_edit` (edits apply silently, bash still
  follows its rules or the gate).

The active mode can be switched at runtime with `/mode`, or set headlessly with
`--yca-run-mode build|plan` on `run`. In `plan` mode read-only tools and the
plan-resolved bash rules run without prompting, write tools follow the
permission mode (denied without an interactive gate), and `write_todo` records
the planned steps; switching back to `build` seeds the todo
list from the last plan when the model did not record it itself.
