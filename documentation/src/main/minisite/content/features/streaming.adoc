= Streaming output and reasoning
:minisite-breadcrumb: Home[index.html] > Features > Streaming output and reasoning

yca streams model output token by token instead of waiting for the full response.
Reasoning/thinking deltas are surfaced separately from the final answer.

In the interactive interfaces the thinking stream is shown as it arrives, and
its verbosity is controlled with the `--showThinking` flag (the TUI also exposes
`/showthinking`). In headless `run` mode, reasoning deltas are printed on
stderr.
