yca ships a set of tools the agent can call to inspect and edit a codebase:
read/write/edit files, directory listing, glob, grep, running `bash`, a todo
list, and a memory store.

This page is the *curated overview* of what the tools do. The exhaustive
reference - every tool with its description, read-only status and JSON schema -
is generated from the running binary on the xref:../tools.adoc[Tools] page.
