The interactive CLI prompt is rendered from a Handlebars template controlled by
`yca.prompt.template` (see xref:../configuration.adoc[Configuration]).

By default the built-in template is used:

[source,handlebars]
----
[{$yupiik.minisite.openbracket$}{#if (eq mode "plan")}}{$yupiik.minisite.openbracket$}{lookup colors "accent"}}{$yupiik.minisite.openbracket$}{else}}{$yupiik.minisite.openbracket$}{lookup colors "success"}}{$yupiik.minisite.openbracket$}{/if}}{$yupiik.minisite.openbracket$}{{mode}}}{$yupiik.minisite.openbracket$}{lookup colors "reset"}}@{$yupiik.minisite.openbracket$}{lookup colors "model"}}{$yupiik.minisite.openbracket$}{{modelName}}}{$yupiik.minisite.openbracket$}{lookup colors "reset"}}]{$yupiik.minisite.openbracket$}{#if permission}} ({$yupiik.minisite.openbracket$}{#if (eq permission "auto")}}{$yupiik.minisite.openbracket$}{lookup colors "warning"}}{$yupiik.minisite.openbracket$}{else}}{$yupiik.minisite.openbracket$}{lookup colors "status"}}{$yupiik.minisite.openbracket$}{/if}}{$yupiik.minisite.openbracket$}{{permission}}}{$yupiik.minisite.openbracket$}{lookup colors "reset"}}){$yupiik.minisite.openbracket$}{/if}}{$yupiik.minisite.openbracket$}{#if agent}} [{$yupiik.minisite.openbracket$}{{agent}}}]{$yupiik.minisite.openbracket$}{/if}} {$yupiik.minisite.openbracket$}{#if (lte model.contextPercentage 30)}}{$yupiik.minisite.openbracket$}{lookup colors "dim"}}{$yupiik.minisite.openbracket$}{else if (lte model.contextPercentage 70)}}{$yupiik.minisite.openbracket$}{lookup colors "warning"}}{$yupiik.minisite.openbracket$}{else}}{$yupiik.minisite.openbracket$}{lookup colors "error"}}{$yupiik.minisite.openbracket$}{/if}}{$yupiik.minisite.openbracket$}{{model.contextPercentage}}}%{$yupiik.minisite.openbracket$}{lookup colors "reset"}}> 
----

which renders, for a build in `yolo` mode with a `reviewer` agent and the context
at 42%:

[source,text]
----
[build@gpt-x] (yolo) [reviewer] 42%> 
----

The context percent is closed with a reset before the `>` prompt glyph and the
line ends with a trailing space, so the chevron and the typed input start
uncolored, one column after the `>`.

Colors and thresholds are expressed directly in the template, so you can tune
them without touching any code.
Every colored segment is closed with `{$yupiik.minisite.openbracket$}{lookup colors "reset"}}` so the following
characters fall back to the default color; when color is disabled the lookup
renders empty.
The optional agent badge only appears when a custom agent is active and the
permission segment only when a permission mode is set.
The context percent is colored dim below 30, warning below 70 and error above.

== Placeholders

[cols="1,1,3",opts=headers]
|===
|Name
|Value
|Description

|`mode`
|`plan` / `build`
|Current agent mode, lowercased.

|`modelName`
|text
|The active model id.

|`model.name`
|text
|Same as `modelName`, nested view.

|`model.contextPercentage`
|number
|Context usage percent of the usable window; `0` until the first turn.

|`model.contextTokens`
|number
|Estimated tokens currently in context; `0` until the first turn. The `~` in
the TUI sidebar marks this as an estimate; when the provider has reported usage
at least once the sidebar adds a `last real` row with the exact provider-billed
`prompt_tokens` of the last anchored request (its absence means the estimate is
heuristic only).

|`model.contextWindow`
|number
|Usable context window in tokens; `0` until the first turn.

|`permission`
|`all` / `yolo` / `auto` / `ask`
|Current permission mode; empty when no mode is set.

|`agent`
|text
|Active custom agent name (from `yca.agents`); empty when none.

|`prune`
|number
|Pruning trigger threshold percent.

|`compact`
|number
|Compaction trigger threshold percent.

|`color`
|boolean
|Whether ANSI color is enabled (`--color on/off`, `NO_COLOR`, or `TERM=dumb`).

|`colors`
|map
|ANSI color palette (name to prefix) resolved from `yca.prompt.colors`; empty when color is disabled. Includes `model` (the active model's color) and `reset` entries.

|`configuration`
|map
|The whole yca configuration as a map, so any configured value is reachable, e.g. `{$yupiik.minisite.openbracket$}{{configuration.provider.providers.0.contextWindow}}}`.
|===

== Helpers

Helpers are plain Handlebars functions usable in the template.
Literal string arguments use double quotes (single quotes are not treated as
quoting).
Sub-expressions compose helpers, e.g. `{$yupiik.minisite.openbracket$}{#if (lte model.contextPercentage 30)}}`,
and `{$yupiik.minisite.openbracket$}{else}}` / `{$yupiik.minisite.openbracket$}{else if ...}}` chains work in block helpers.
`{$yupiik.minisite.openbracket$}{value}}` escapes the value while `{$yupiik.minisite.openbracket$}{{value}}}` renders it raw - use triple
braces for values containing ANSI escape sequences like mode, model name or
palette colors.

`{$yupiik.minisite.openbracket$}{lookup colors "name"}}` pulls the ANSI prefix named `name` from the `colors`
palette and renders empty when the entry is missing, letting the value degrade
to plain text.
Recognized palette names:

[cols="1,3",opts=headers]
|===
|Name
|Result

|`model`
|The active model's configured style (from the model style service).

|`accent` / `success` / `error` / `warning` / `status` / `info` / `dim` / `bold`
|The matching ANSI color/style directly.

|`reset`
|The ANSI reset sequence (SGR 0) closing each colored segment.
|===

The palette itself is the `yca.prompt.colors` configuration entry (a name to
ANSI prefix map), so custom names can be added there and looked up the same
way.
When ANSI color is disabled (`--color off`, `NO_COLOR`, or `TERM=dumb`), the
`colors` palette is empty and lookups render empty.

== Conditionals

Built-in block helpers drop empty segments: `{$yupiik.minisite.openbracket$}{#if ...}}` is falsy for null,
blank, or empty values.

[source,handlebars]
----
{$yupiik.minisite.openbracket$}{#if permission}} ({$yupiik.minisite.openbracket$}{{permission}}}){$yupiik.minisite.openbracket$}{/if}}{$yupiik.minisite.openbracket$}{#if agent}} [{$yupiik.minisite.openbracket$}{{agent}}}]{$yupiik.minisite.openbracket$}{/if}}
----

`{$yupiik.minisite.openbracket$}{else}}` and `{$yupiik.minisite.openbracket$}{else if ...}}` cover the fallback branches, as used by the
context thresholds of the built-in template:

[source,handlebars]
----
{$yupiik.minisite.openbracket$}{#if (lte model.contextPercentage 30)}}{$yupiik.minisite.openbracket$}{lookup colors "dim"}}{$yupiik.minisite.openbracket$}{else if (lte model.contextPercentage 70)}}{$yupiik.minisite.openbracket$}{lookup colors "warning"}}{$yupiik.minisite.openbracket$}{else}}{$yupiik.minisite.openbracket$}{lookup colors "error"}}{$yupiik.minisite.openbracket$}{/if}}
----
